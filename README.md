# QuizDock community store

A catalogue of quiz templates for [QuizDock](https://github.com/quizdock/quiz-dock), the self-hosted live quiz. Authors publish their quizzes from their own GitHub repository; any QuizDock instance can browse the catalogue and import a copy.

Submissions are not open yet.

- [How to publish your quizzes](CONTRIBUTING.md)
- [How the store works](SPECIFICATION.md)
- [Running a closed store for your organisation](SELF-HOSTING.md)

The store is optional: QuizDock works fully without it, offline included.
